01 / O projeto

Software de quadros para pequenas e grandes ambições

O Framework reúne numa única aplicação tudo o que é preciso para projetar um quadro de bicicleta: geometria, tubos, componentes, análise e fabrico. Tanto para construtores amadores como para oficinas profissionais.

Porquê

Partir da bicicleta

Projetar um quadro costuma significar andar entre folhas de cálculo, CAD genérico, catálogos de tubos e notas de oficina. O Framework parte da bicicleta, não de um software mecânico genérico.

Como

Tudo fica ligado

Uma geometria paramétrica guiada por onze cotas, um solucionador de restrições, referências reais de tubos e componentes, depois análise e desenhos de oficina. Altere uma cota e tudo se atualiza.

O quê

Uma aplicação de secretária

Funciona offline, em unidades métricas ou imperiais, com a interface em cinco idiomas. Os seus projetos ficam no seu computador.

01 / El proyecto

Software de cuadros para ambiciones pequeñas y grandes

Framework reúne en una sola aplicación todo lo necesario para diseñar un cuadro de bicicleta: geometría, tubos, componentes, análisis y fabricación. Tanto para constructores aficionados como para talleres profesionales.

Por qué

Partir de la bicicleta

Diseñar un cuadro suele significar manejar hojas de cálculo, CAD genérico, catálogos de tubos y notas de taller. Framework parte de la bicicleta, no de un software mecánico genérico.

Cómo

Todo permanece conectado

Una geometría paramétrica guiada por once dimensiones, un solucionador de restricciones, referencias reales de tubos y componentes, y después análisis y planos de taller. Cambia una dimensión y todo se actualiza.

Qué

Una aplicación de escritorio

Funciona sin conexión, en unidades métricas o imperiales, con la interfaz en cinco idiomas. Tus proyectos se quedan en tu ordenador.

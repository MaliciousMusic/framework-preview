为大小志向而生的车架设计软件

Framework 把设计自行车车架所需的一切整合在一个应用中:几何、管材、零部件、分析和制造。无论是业余制架爱好者还是专业工坊,都能使用。

为什么

从自行车出发

设计车架通常意味着在电子表格、通用 CAD、管材目录和工坊笔记之间来回切换。Framework 从自行车本身出发,而不是从通用机械软件出发。

怎么做

一切保持关联

由十一个尺寸驱动的参数化几何、约束求解器、真实的管材和零部件数据,再到分析和工坊图纸。修改一个尺寸,一切随之更新。

是什么

桌面应用

可离线运行,支持公制和英制单位,界面提供五种语言。你的项目保存在你自己的电脑上。
